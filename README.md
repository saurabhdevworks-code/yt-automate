# NotebookLM-only Hindi YouTube pipeline with GitHub Actions

This project automates topic discovery, creates a NotebookLM-ready research pack, drafts metadata, and uploads a NotebookLM-generated MP4 to YouTube.

## Non-negotiable video rule
The final video must be generated by **Google NotebookLM Video Overview only**. This repository does not use another video generator.

## Video Post-Processing Features
1. **Auto Outro Trimming (Last 3s)**: In `auto` mode, the pipeline automatically detects video duration and trims off the final 3 seconds to cleanly remove the default NotebookLM ending outro screen (`"Made with NotebookLM"`).
2. **NotebookLM Watermark Removal & Custom Branding**:
   - **Watermark Removal**: The NotebookLM watermark in the bottom-right corner is automatically removed using FFmpeg `delogo` spatial interpolation.
   - **Custom Branding Image (Optional)**:
     - If you place an image in `assets/images/` named `watermark` (e.g. `assets/images/watermark.png`, `watermark.jpg`, `watermark.webp`) or provide an image link via `custom_watermark_url`, the pipeline removes the watermark and overlays your custom logo in its place.
     - If **no image** is placed in `assets/images/`, the pipeline cleanly removes the NotebookLM watermark with `delogo` without adding any replacement image.

## Setup
1. Push this project to a GitHub repository.
2. Edit `config/settings.json` with your niche/audience.
3. Add GitHub Actions secrets:
   - `GEMINI_API_KEY` (optional; used for metadata only; model access/free-tier terms vary)
   - `YOUTUBE_CLIENT_ID`
   - `YOUTUBE_CLIENT_SECRET`
   - `YOUTUBE_REFRESH_TOKEN`
4. Enable YouTube Data API v3 in Google Cloud and create an OAuth client. Run `python scripts/get_youtube_refresh_token.py --client-secrets client_secret.json` locally to obtain the refresh token. Never commit credentials.
5. Trigger **Full NotebookLM Pipeline (100% Cloud Server - No PC Required)** in GitHub Actions (supports `auto` and `custom` modes).
6. Uploaded videos default to `private` mode for quality checks before public viewing.

## Thumbnail font
For exact Hindi rendering, add a licensed Devanagari font at `assets/fonts/NotoSansDevanagari-Bold.ttf`. If absent, thumbnail generation is skipped with a warning; upload still works.
