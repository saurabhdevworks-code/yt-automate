# NotebookLM-only Hindi YouTube pipeline with GitHub Actions

This project automates topic discovery, creates a NotebookLM-ready research pack, drafts metadata, and uploads a NotebookLM-generated MP4 to YouTube.

## Non-negotiable video rule
The final video must be generated by **Google NotebookLM Video Overview only**. This repository does not use another video generator.

## Important limitation
NotebookLM's published instructions describe creating a Video Overview in the NotebookLM interface; they do not document a general public API for automating notebook creation, generation, and video download end-to-end. Therefore the research workflow runs automatically, then you perform the NotebookLM generation/download step. The upload workflow resumes automatically when you provide a direct HTTPS download URL for the MP4. It does not fake an unsupported NotebookLM API.

Official docs:
- NotebookLM Video Overview: https://support.google.com/notebooklm/answer/16454555
- YouTube video upload: https://developers.google.com/youtube/v3/guides/uploading_a_video

## Setup
1. Push this project to a GitHub repository.
2. Edit `config/settings.json` with your niche/audience.
3. Add GitHub Actions secrets:
   - `GEMINI_API_KEY` (optional; used for metadata only; model access/free-tier terms vary)
   - `YOUTUBE_CLIENT_ID`
   - `YOUTUBE_CLIENT_SECRET`
   - `YOUTUBE_REFRESH_TOKEN`
4. Enable YouTube Data API v3 in Google Cloud and create an OAuth client. Run `python scripts/get_youtube_refresh_token.py --client-secrets client_secret.json` locally to obtain the refresh token. Never commit credentials.
5. Run the `Research & NotebookLM Pack` workflow manually or wait for the daily schedule. Download its artifact.
6. Review the sources, add them to NotebookLM, select Studio → Video Overview, choose Hindi if available, paste `notebooklm_prompt.txt`, generate and download the MP4.
7. Trigger `Upload NotebookLM Video` and provide a direct HTTPS MP4 URL, metadata JSON, and privacy `private` or `unlisted`.
8. Download the `youtube-upload-result` artifact to get the YouTube URL.

## Thumbnail font
For exact Hindi rendering, add a licensed Devanagari font at `assets/fonts/NotoSansDevanagari-Bold.ttf`. If absent, thumbnail generation is skipped with a warning; upload still works. You may also supply a background image URL to the upload workflow.

## Honest limitations
- GitHub Actions cannot automatically access your logged-in NotebookLM browser session.
- Google Drive share links may not be direct download links.
- Exact 4–8 minute output is not guaranteed by NotebookLM; inspect duration and quality.
- Search results are topic leads, not proof or search-volume metrics. Verify claims and sources.
- YouTube OAuth, quota and account eligibility requirements apply.
- Upload defaults to private. Do not expose private MP4s on public hosts just to automate.
