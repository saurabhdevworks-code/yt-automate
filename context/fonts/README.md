### ➕ Naya Font Kaise Add Karein?
Agar aapko koi naya font pasand aaye (e.g. *Rozha One, Khand, Rajdhani, Gotu*):
1. Uska `.ttf` file download karein.
2. Is folder (`context/fonts/`) me paste kar dein.
3. System automatically use load kar lega!
