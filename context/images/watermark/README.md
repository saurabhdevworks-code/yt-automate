# Watermark Image Placement

Apna custom channel logo ya watermark yahan save karein:
- File name: `watermark.png` ya `watermark.jpg`

### Kaise Kaam Karega:
1. Agar yahan `watermark.png` hoga, toh NotebookLM ka watermark remove karke uski jagah aapka logo lag jayega.
2. Agar yahan koi image nahi hogi, toh video me se watermark cleanly delete ho jayega (clean video).
