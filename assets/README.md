# Assets Directory

This directory contains assets used by the automation pipeline:

- `watermark.png`: Logo/badge image automatically overlaid in the bottom-right corner of NotebookLM videos to cover the NotebookLM watermark.
  - To use your own channel logo, simply replace `watermark.png` (or add `logo.png` / `channel_logo.png`).
  - Recommended dimensions: ~280x70px or standard square/rectangle PNG with high resolution.
- `fonts/`: TTF fonts for YouTube thumbnail rendering.
